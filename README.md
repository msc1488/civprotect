# CivProtect v2.0

Плагин для Minecraft серверов (Paper 1.20-1.21.11) для защиты от злоупотребления правами администратора.

## Возможности

- 🔒 **Защита от звёздочек** — автоматический бан игроков с правами `*`, `luckperms.*`, `bukkit.*`, `minecraft.*`, `*.*`
- 👑 **Защита от незаконного OP** — бан игроков с статусом OP
- 📝 **Два белых списка** — отдельно для звёздочек и для OP
- 📢 **Discord Webhook** — уведомления о банах в Embed формате с аватаром игрока
- ⚙️ **Настраиваемые причины бана** — разные причины для звёздочек и OP

## Установка

1. Скачайте `CivProtect-2.0.jar`
2. Положите в папку `plugins` вашего сервера
3. Перезапустите сервер (или выполните `/reload`)
4. Настройте `config.yml` под свои нужды

## Конфигурация (config.yml)

```yaml
# Автор плагина: mscgroup
# Версия: 2.0
webhook-url: "https://discord.com/api/webhooks/ВАШ_ВЕБХУК"

# Бан за звёздочку
ban-reason-star: "&c[CivProtect] На вашем аккаунте обнаружены опасные права!"
webhook-message-star: "Игрок **{player}** попытался войти со звёздочкой в правах и был забанен."

# Бан за OP
ban-reason-op: "&c[CivProtect] Вы были забанены за незаконное использование прав администратора!"
webhook-message-op: "⚠️ Игрок **{player}** (OP) был забанен за злоупотребление правами."

# Белый список для звёздочек
whitelist-star:
  - "mscgroup"

# Белый список для OP
whitelist-op:
  - "mscgroup"
```

## Команды

| Команда | Описание |
|---------|----------|
| `/civprotect list` | Показать оба белых списка |
| `/civprotect addstar <ник>` | Добавить игрока в whitelist-star |
| `/civprotect removestar <ник>` | Удалить игрока из whitelist-star |
| `/civprotect addop <ник>` | Добавить игрока в whitelist-op |
| `/civprotect removeop <ник>` | Удалить игрока из whitelist-op |
| `/civprotect reload` | Перезагрузить конфиг |
| `/unbanstar <ник>` | Разбанить игрока |

## Права

- `civprotect.admin` — доступ ко всем командам `/civprotect`
- `civprotect.unban` — доступ к команде `/unbanstar`

## Как это работает

1. При входе и каждом тике игрок проверяется на наличие опасных прав
2. Если у игрока есть звёздочки (`*`, `luckperms.*`, etc.) и он НЕ в whitelist-star → бан
3. Если игрок имеет OP статус и НЕ в whitelist-op → бан
4. Бан отправляется в Discord через Webhook в виде Embed с аватаром игрока

## Цвета в сообщениях

Используйте `&` для кодов цветов:
- `&c` — красный
- `&a` — зелёный
- `&e` — жёлтый
- `&b` — голубой

## Важное замечание

**При выдаче OP на Paper серверах игроку автоматически присваиваются права `*`, `bukkit.*`, `minecraft.*`**.
Это значит:
- Игроку с OP статусом **нужно добавлять в `whitelist-op`** командой `/civprotect addop <ник>`
- `whitelist-op` даёт полный иммунитет — игрок игнорирует проверку как на OP, так и на звёздочки
- Если не добавить игрока в `whitelist-op`, плагин увидит звёздочки от OP и забанит за звёздочку

**Решение проблемы:**
```bash
# 1. Добавить игрока в whitelist-op
/civprotect addop <ник>

# 2. Разбанить если уже забанен
/unbanstar <ник>
```
